# Self-Supervised Learning for Seismic Facies Segmentation

This repository contains the paper:

"The Impact of Pretraining Task and Data Domains on Transfer Learning for Seismic Facies Segmentation"

## Summary
- Investigates BYOL for seismic data
- Compares with ImageNet / COCO pretraining
- Shows strong performance gains in low-data regimes

## Authors
Vinicius Leme Soares et al.
